Taruh file foto Anda di folder ini sesuai kategori:

- public/images/berita/   -> foto untuk setiap berita (nama file harus sama persis dengan kolom 'gambar' di database, contoh: berita-1.jpg)
- public/images/galeri/   -> foto untuk galeri kegiatan (contoh: galeri-1.jpg)
- public/images/umum/     -> foto umum: logo, hero/banner, foto "tentang kami"
  Nama file yang dipakai kode:
    - logo.png       (logo sekolah, tampil di navbar)
    - hero-bg.jpg    (foto latar belakang section hero di halaman Beranda)
    - tentang-kami.jpg (foto section "Tentang Kami" di halaman Beranda)

Kalau file belum ada, halaman otomatis menampilkan kotak abu-abu placeholder (tidak error).
Setelah file foto ditaruh dengan nama yang benar, foto otomatis muncul menggantikan kotak abu-abu.
